GitHub Actions CI/CD configuration: automated Linux build of the bootloader and
tag-driven GitHub Releases.

### .github/workflows/
- **Responsibility:** Build the UNO R4 Minima bootloader on every push/PR and publish a versioned GitHub Release when a `v*` tag is pushed.
- **Key files:** `release.yml`
- **Relationships:** runs `scripts/ci-build.sh` (which builds `vendor/arduino-renesas-bootloader` and enforces the size gate); pins the same xPack `arm-none-eabi-gcc` version documented in `docs/build.md`; produces the release artifacts referenced by `README.md`'s Releases section.

- **release.yml** — Two-job workflow. `build` (on push to `main`, `v*` tags, PRs to `main`, and `workflow_dispatch`): checks out, caches/installs xPack `arm-none-eabi-gcc 14.2.1-1.1` (Linux x64) onto PATH, runs `scripts/ci-build.sh`, renames the outputs to `bootloader-uno_r4-<version>.{hex,bin,elf}` (version = tag name on tags, short SHA otherwise), and uploads them as build artifacts. `release` (only on `v*` tags, `permissions: contents: write`): downloads the artifacts and creates a GitHub Release via `softprops/action-gh-release@v2` with auto-generated notes.
