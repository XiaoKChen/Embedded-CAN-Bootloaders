The pure-C11, host-testable logic core (`src/boot/`): config constants, CRC32, the CAN Update Protocol v1 engine, the APP_INFO/ENTER_UPDATER codec, the boot-counter recovery log, the config-block parser, the `.ecbpkg` package parser, and RA4M1 prior-art image validation. No file here touches hardware.

### boot/
- **Responsibility:** Hardware-free C11 logic shared by the ESP32-S3 node updater, node app, brain, the host CAN flasher and the host Unity tests: protocol codecs, CRC, validation and parsing, with no peripheral or flash access.
- **Key files:** `can_update.{c,h}`, `app_control.{c,h}`, `boot_counter.{c,h}`, `dfu_config.{c,h}`, `update_pkg.{c,h}`, `crc32.{c,h}`, `image_validate.{c,h}`, `memory_map.h`, `boot_config.h`, `image_header.h`
- **Relationships:** Depends only on `<stdint.h>`, `<stdbool.h>`, `<stddef.h>`, `<string.h>`. Internal edges: `can_update.h` → `boot_config.h`; `can_update.c` → `crc32.h`; `app_control.h` → `can_update.h`; `app_control.c` → `crc32.h`; `dfu_config.c` → `boot_config.h`, `crc32.h`; `image_header.h` → `boot_config.h`; `image_validate.h` → `image_header.h`, `memory_map.h`; `image_validate.c` → `crc32.h`; `update_pkg.c` → `crc32.h`; `boot_counter.c` standalone. Exposes: `crc32_ieee`, `crc32_ieee_update`, `can_update_init`, `can_update_handle_frame`, `can_update_hal_t`, `app_control_*`, `dfu_config_parse`, `dfu_config_can_ids`, `boot_counter_rtc_*`, `boot_counter_log_scan`, `boot_counter_log_wrap`, `boot_counter_record`, `update_pkg_parse`, `update_pkg_status_text`, `image_validate`.

**Compile map (who builds each file):**
- `components/boot_core` compiles `can_update.c`, `crc32.c`, `dfu_config.c` (INCLUDE_DIRS = `src/boot`); consumed by `node_updater/main`, `brain/main`, `examples/node_app/main` and `components/can_flash_host`.
- `app_control.c` is compiled by `components/can_flash_host` (host side) and `examples/node_app/main` (node side); `boot_core` deliberately does not.
- `boot_counter.c` is compiled by `components/can_updater_client` and by `node_updater/bootloader_components/main` (2nd-stage bootloader).
- `update_pkg.c` is compiled directly by `brain/main`.
- `tests/CMakeLists.txt` builds all of them plus `image_validate.c` into the host `boot_core` library. No firmware target compiles `image_validate.c`; `memory_map.h`, `image_header.h`, `image_validate.h` are host-only.

- **memory_map.h** — RA4M1 flash/RAM partition constants (BOOT 16 KB, APP_BASE 0x4000, APP slot 0x3B800, metadata at 0x3F800, data-flash config at 0x40101C00, SRAM bounds) with `_Static_assert` checks. Host-only prior art.
- **boot_config.h** — Default CAN update IDs (`CAN_ID_HOST_TO_BOOT` 0x79E, `CAN_ID_BOOT_TO_HOST` 0x79F), `CAN_BITRATE_BPS` 250000, `CAN_UPDATE_MAGIC`, `IMAGE_META_MAGIC`.
- **image_header.h** — `image_meta_t`, the 16-byte little-endian metadata record (magic, image_size, image_crc32, header_crc32). Host-only.
- **crc32.h / crc32.c** — `crc32_ieee` and streaming `crc32_ieee_update`, IEEE 802.3, table-less.
- **can_update.h / can_update.c** — CAN Update Protocol v1 engine: `can_update_hal_t` slot HAL, phase/action enums, `can_update_init`, `can_update_handle_frame` for HELLO/SIZE/ERASE/DATA/VERIFY/GO/INFO with windowed DATA and fail-closed phases; NAKs app-control opcodes in every phase.
- **app_control.h / app_control.c** — Codec for APP_INFO (0x08) and ENTER_UPDATER (0x09): node side parses and replies, host side encodes and classifies replies (app ACK marker 0xA5 vs updater STATE NAK vs silence).
- **boot_counter.h / boot_counter.c** — Recovery counter: validated RTC record (`boot_counter_rtc_*`, `BOOT_COUNTER_LIMIT` 3) and an append-only 16-byte flash record log (`boot_counter_log_scan`/`_wrap`).
- **dfu_config.h / dfu_config.c** — Parser for the v1 (76 B) and v2 (80 B) config block: magic, version, CRC, name strings (`dfu_config_parse`) and per-device CAN IDs (`dfu_config_can_ids`, falling back to `boot_config.h`).
- **update_pkg.h / update_pkg.c** — Parser for the `ECBPKG` v1 update package (32-byte header + 96-byte entries, up to 8 nodes + brain), returning `update_pkg_status_t`.
- **image_validate.h / image_validate.c** — Fail-closed validation of the RA4M1 image metadata block over a byte buffer; host-tested prior art, not used by ESP32-S3 firmware.
