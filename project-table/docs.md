### docs/reference/
- **Responsibility:** Byte-exact third-party reference artifacts used to validate the custom bootloader build (unbrick target, OFS/ID-code byte comparison, linker-section template) — not built from source in this repo.
- **Key files:** `dfu_minima.hex`, `minima_fsp.ld`
- **Relationships:** Consumed directly by `docs/build.md`'s flashing/unbrick commands (`pyocd flash`, `rfp-cli`) and pre-flash OFS check (`od` byte dump compared against this file's `:10040000`–`:10043000` records); `minima_fsp.ld` is the template `src/boot/memory_map.h` and the fork's linker script must stay consistent with.

- **dfu_minima.hex** — Arduino's stock UNO R4 Minima bootloader, Intel HEX format (783 lines, ~35 KB text for a 12,424-byte binary). Used as the unbrick/restore image (`pyocd flash -e sector -a 0x0 -t r7fa4m1ab docs/reference/dfu_minima.hex`) and as the byte-exact reference for verifying OFS0/OFS1/Security-MPU words at flash `0x400`–`0x43F` before first-flashing the custom build.
- **minima_fsp.ld** — Reference Renesas-FSP linker script (10,463 bytes) defining the `FLASH`/`RAM`/`DATA_FLASH`/`OPTION_SETTING`/`ID_CODE` memory regions and sections (`.sketch_boot`, `.fixed_vectors`, `.option_setting_ofs0`/`ofs1`, `.id_code`, `.data_flash`, `.noinit`, `.heap`), `ENTRY(Reset_Handler)`. Serves as the template/ground-truth for the fork's own linker script and for `src/boot/memory_map.h`'s address constants.
