- **test_image_validate.c** — Exercises `image_validate()` against a fake 256 KB flash buffer; covers every result — valid, bad magic, header-CRC corruption, size zero/below-min/above-slot/at-boundary, SP below/at-base/above-end, entry in bootloader/metadata region/Thumb-clear, payload-CRC corruption.

- **test_dfu_config.c** — Tests `dfu_config_parse()` against a 76-byte fake config blob; covers valid round-trip, erased/bad magic, bad version, over-max lengths, at-max boundary, bad CRC, mutated payload, and empty-string boundary.
