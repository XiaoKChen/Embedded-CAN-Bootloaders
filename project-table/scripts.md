- **ci-build.sh** — Bash (`set -euo pipefail`) helper run from the repo root. Prints the toolchain version, shallow-fetches `renesas/fsp` and `ARM-software/CMSIS_5` at the commits pinned in `docs/build.md` (only if absent), then runs `make -f Makefile.minima BOARD=uno_r4 TINYUSB_ROOT=../tinyusb CAN_LOADER=1 DFU_CUSTOM_NAME=1 -j$(nproc)` and lists the resulting `.elf`/`.bin`/`.hex`. The Makefile's 16,384-byte size gate fails the build if the bootloader region is exceeded. Requires xPack `arm-none-eabi-gcc` 14.2.1 and GNU make already on PATH.
