# node_updater/
> Generated by /map. Do not edit manually — re-run /map to refresh.

The ESP32-S3 node's ESP-IDF "factory" CAN updater app and its 2nd-stage bootloader override; it parks on the TWAI bus serving CAN Update Protocol v1 and boots the updater whenever no OTA app is selected or validated.

### node_updater/
- **Responsibility:** ESP-IDF project root for the node updater; selects the components, config defaults, and partition table, and wires in the shared `components/` and `src/boot/` code.
- **Key files:** `CMakeLists.txt`, `sdkconfig.defaults`, `partitions.csv`
- **Relationships:** imports from: `../components/` (via `EXTRA_COMPONENT_DIRS`), `main/` and `bootloader_components/` (via IDF component discovery) — exposes: project `can_updater` (targets `main` and `can_updater_client` components)

- **CMakeLists.txt** — top-level ESP-IDF project file; sets `COMPONENTS main can_updater_client`, points `EXTRA_COMPONENT_DIRS` at `../components`, and raises `CMAKE_OBJECT_PATH_MAX` to 259 on Windows.
- **sdkconfig.defaults** — committed config: ESP32-S3 target, 4 MB flash, custom partition table, rollback enabled, RTC reserve of 0x10 bytes, no GPIO factory reset (GPIO4 is TWAI TX), task-WDT panic.
- **partitions.csv** — 4 MB table: nvs, otadata, phy_init, `cancfg` (0x40), `bootcnt` (0x42), `factory` (0x20000, 0x60000), `ota_0`, `ota_1`; every node OTA app builds against it.

### bootloader_components/main/
- **Responsibility:** The 2nd-stage bootloader override component; replaces IDF's `call_start_cpu0` to apply the recovery counter decision before otadata selection, then hands off to IDF's normal image loader.
- **Key files:** `CMakeLists.txt`, `boot.c`
- **Relationships:** imports from: `../../../src/boot/` (`boot_counter.c`, `boot_counter.h`), ESP-IDF `bootloader`, `bootloader_support`, `spi_flash` components — exposes: `call_start_cpu0`, `__getreent` (stub)

- **CMakeLists.txt** — registers `boot.c` plus `src/boot/boot_counter.c` with include dir `src/boot`, requires `bootloader`/`bootloader_support`/`spi_flash`, and adds IDF's bootloader linker scripts for the target.
- **boot.c** — overrides `call_start_cpu0`: classifies the reset, reads and writes the RTC and flash boot counters, forces `FACTORY_INDEX` on a latched trip, otherwise uses IDF's selected partition, then loads the image; `__getreent` returns `_GLOBAL_REENT`.

### main/
- **Responsibility:** The `factory` app: a parked CAN service that answers HELLO/INFO, receives an image into the inactive OTA slot with read-back verification, and switches the boot partition on GO.
- **Key files:** `main.c`, `Kconfig.projbuild`, `CMakeLists.txt`
- **Relationships:** imports from: `components/can_updater_client` (`can_updater_client_start_health`, `can_updater_client_prepare_verified_boot`), `components/can_link` (`can_link_init`, `can_link_send`, `can_link_receive`, `can_link_deinit`), `src/boot/can_update` (`can_update_init`, `can_update_handle_frame`), `src/boot/dfu_config` (`dfu_config_can_ids`, `dfu_config_parse`), ESP-IDF OTA and partition APIs — exposes: `app_main`; Kconfig symbols `CAN_UPDATER_TWAI_TX_GPIO`, `CAN_UPDATER_TWAI_RX_GPIO`, `CAN_UPDATER_BITRATE_BPS`

- **CMakeLists.txt** — registers `main.c` with include dir `.` and requires `boot_core`, `can_link`, `app_update`, `esp_partition`, `can_updater_client`.
- **Kconfig.projbuild** — "CAN Updater" menu: TWAI TX GPIO (default 4), RX GPIO (default 5), and a bitrate choice (125k/250k default/500k/1M) that derives `CAN_UPDATER_BITRATE_BPS`.
- **main.c** — `app_main` starts the health task, loads the `cancfg` block for CAN IDs and INFO name, targets the next OTA slot, then serves the update engine over TWAI with the task watchdog; a verified GO clears the recovery counters, selects the new slot and restarts.
