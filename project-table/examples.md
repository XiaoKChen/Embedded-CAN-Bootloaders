### examples/node_app/
- **Responsibility:** Reference ESP-IDF CAN-updatable node application illustrating health/recovery startup, CAN update service setup, and the node application handoff. (Stock Arduino-ESP32 apps use `components/arduino_node_app/` instead.)
- **Key files:** `CMakeLists.txt`, `main/node_app.c`, `main/can_service.c`, `main/can_service.h`, `main/CMakeLists.txt`, `main/Kconfig.projbuild`.

- **main/Kconfig.projbuild** — Defines the app's TWAI pins and bitrate, which must match the updater's (the board profile in `cancfg`, or GPIO4/5 at 250 kbit/s by default).
