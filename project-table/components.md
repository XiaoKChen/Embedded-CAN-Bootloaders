# components/
> Generated by /map. Do not edit manually — re-run /map to refresh.

Shared ESP-IDF components for the ESP32-S3 brain/node CAN update system: they compile the shared `src/boot/` protocol core into firmware and provide the host-side flashing protocol, the TWAI CAN link, the brain's node reset line, the app-side updater entry with recovery counters, and a pure SLCAN codec.

### boot_core/
- **Responsibility:** Compiles the shared pure-logic CAN update core from `src/boot/` into ESP-IDF firmware, adding no logic of its own.
- **Key files:** CMakeLists.txt
- **Relationships:** imports from: src/boot/ — exposes: can_update_init, can_update_handle_frame, crc32_ieee, crc32_ieee_update, dfu_config_parse, dfu_config_can_ids (headers in src/boot/ exported via INCLUDE_DIRS)
- **CMakeLists.txt** — `SRCS` `src/boot/can_update.c`, `crc32.c`, `dfu_config.c`; `INCLUDE_DIRS` `src/boot/`.

### can_flash_host/
- **Responsibility:** Blocking, allocation-free host implementation of CAN Update Protocol v1 (info, scan, flash, app-info, enter-updater) over caller-injected send, receive, clock, read and progress callbacks; runs on the brain and in host tests.
- **Key files:** can_flash_host.c, include/can_flash_host.h
- **Relationships:** imports from: boot_core/ and src/boot/ (`app_control.h`, `can_update.h`, `dfu_config.h`, `crc32.h`) — exposes: can_flash_host_info, can_flash_host_scan, can_flash_host_discover, can_flash_host_flash, can_flash_host_app_info, can_flash_host_enter_updater, can_flash_host_result_text, can_flash_host_t, can_flash_host_status_t
- **can_flash_host.c** — Send/receive/drain helpers, the INFO/scan probe, the windowed DATA transfer with VERIFY recovery, and app-control requests.
- **include/can_flash_host.h** — Status and step enums, the injected-callback context `can_flash_host_t`, timing constants, result-text diagnostics.
- **CMakeLists.txt** — Compiles `can_flash_host.c` plus `src/boot/app_control.c`, exposes `include/`, `REQUIRES boot_core`.

### can_link/
- **Responsibility:** Thin wrapper over the ESP-IDF v5.3 legacy TWAI driver for classic CAN, with hardware single-ID filtering, bus-off recovery, and a receive/transmit API free of IDF types.
- **Key files:** can_link.c, include/can_link.h
- **Relationships:** imports from: driver (ESP-IDF, `PRIV_REQUIRES driver`) — exposes: can_link_init, can_link_receive, can_link_receive_frame, can_link_send, can_link_send_frame, can_link_get_health, can_link_deinit, can_link_config_t, can_link_frame_t, can_link_health_t. Used by node_updater, brain, examples/node_app and examples/slcan_bridge.
- **can_link.c** — Init (timing from bitrate, filter selection, driver install and start), frame receive/transmit with recovery on timeout or failure, health snapshot, bounded drain before uninstall.
- **include/can_link.h** — Public types (`can_link_config_t`, `can_link_frame_t`, `can_link_bus_state_t`, `can_link_health_t`) and function declarations.
- **CMakeLists.txt** — Compiles `can_link.c`, exposes `include/`, requires `driver` privately.

### can_updater_client/
- **Responsibility:** App-side entry into the CAN updater (select `factory`, restart) and the recovery-counter health client (clean-restart mark, 10 s stable-uptime clear, verified-GO clear).
- **Key files:** can_updater_client.c, recovery.c, include/can_updater_client.h
- **Relationships:** imports from: src/boot/ (`boot_counter.h`, `boot_counter.c` compiled in) plus ESP-IDF `app_update`, `esp_partition`, `bootloader_support` — exposes: can_updater_client_enter_updater, can_updater_client_start_health, can_updater_client_prepare_verified_boot. Used by node_updater, examples/node_app, examples/bench_app.
- **can_updater_client.c** — `can_updater_client_enter_updater()`: find the factory app partition, set it as the boot partition, `esp_restart()`.
- **recovery.c** — Shutdown handler for clean-restart marking, a static 10 s stable-uptime task, mutex-guarded counter clearing of the `bootcnt` flash log and RTC counter; compile-time checks that the RTC reserve is 0x10 bytes and excluded from CRC.
- **include/can_updater_client.h** — Public API for the three functions above, plus the required sdkconfig notes.
- **CMakeLists.txt** — Compiles `can_updater_client.c`, `recovery.c` and `src/boot/boot_counter.c`, exposes `include/`, adds `src/boot/` as a private include dir.

### node_reset/
- **Responsibility:** Drives the brain's reset line to the node (`CONFIG_NODE_RESET_GPIO`, default 3, inverted: HIGH resets, LOW runs), including a recovery pulse train that always finishes LOW.
- **Key files:** node_reset.c, include/node_reset.h, Kconfig
- **Relationships:** imports from: ESP-IDF `esp_driver_gpio`, `freertos` — exposes: node_reset_release, node_reset_pulse_train, NODE_RESET_RECOVERY_PULSES, NODE_RESET_RECOVERY_HIGH_MS, NODE_RESET_RECOVERY_LOW_MS. Shared by `brain/` and `examples/slcan_bridge`.
- **node_reset.c** — Release (latch LOW, then configure output) and the pulse train, releasing the line on every exit path.
- **include/node_reset.h** — Public API and the recovery pulse constants (4 pulses, 100 ms high, 400 ms low).
- **Kconfig** — `NODE_RESET_GPIO` (range 0..48, default 3) under the "Node reset line" menu.
- **CMakeLists.txt** — Compiles `node_reset.c`, exposes `include/`, requires `esp_driver_gpio` and `freertos` privately.

### slcan_codec/
- **Responsibility:** Pure-logic SLCAN (Lawicel) line parser and encoder for the subset python-can's slcan backend uses; no ESP-IDF dependencies.
- **Key files:** slcan_codec.c, include/slcan_codec.h
- **Relationships:** imports from: standard C only — exposes: slcan_parse_line, slcan_encode_frame, slcan_encode_version, slcan_encode_serial, slcan_frame_t, slcan_command_t, slcan_status_t. Used by examples/slcan_bridge; host-tested by tests/test_slcan_codec.c.
- **slcan_codec.c** — `slcan_parse_line` (command dispatch, S0..S8 bitrate table, frame parsing with hex and DLC checks) and the frame, version (`Vhhss`) and serial (`Nxxxx`) encoders.
- **include/slcan_codec.h** — Wire constants, status codes, command and frame types, parse/encode declarations, supported-command table.
- **CMakeLists.txt** — Compiles `slcan_codec.c`, exposes `include/`; no `REQUIRES`.
