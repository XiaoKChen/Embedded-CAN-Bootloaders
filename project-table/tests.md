# tests/
> Generated by /map. Do not edit manually — re-run /map to refresh.

Host-side Unity/CTest suite that builds the pure-logic core, the SLCAN codec and the CAN flash host on x86 and runs nine test executables without target hardware.

### tests/
- **Responsibility:** Builds the host test executables and their static libraries, and holds the unit and protocol tests for the pure-logic core.
- **Key files:** CMakeLists.txt, test_can_update.c, test_can_flash_host.c, test_boot_counter.c, test_update_pkg.c, vectors/sample.ecbpkg
- **Relationships:** imports from: src/boot/ (via CMake BOOT_DIR), components/slcan_codec/, components/can_flash_host/, unity/, vectors/ — exposes: none (test executables only)

- **CMakeLists.txt** — Builds static libraries unity, boot_core (update_pkg, boot_counter, crc32, image_validate, can_update, dfu_config, app_control), slcan_codec and can_flash_host; registers nine CTest executables through add_host_test() and passes the sample vector path to test_update_pkg as UPDATE_PKG_VECTOR.
- **test_update_pkg.c** — Update package parser: valid single and multi-entry packages, magic and version checks, truncation, payload bounds, entry counts, types and flags, names and IDs, and the checked-in sample.ecbpkg (7 tests).
- **test_boot_counter.c** — Boot-loop counter: RTC threshold with sticky trip, one-use clean-restart mark, garbage and power-on handling, torn-write bit flips, full-log wrap and trip, empty/truncated logs, verified-boot clear releasing both latches (8 tests).
- **test_crc32.c** — IEEE 802.3 CRC32 golden vectors: 0xCBF43926 for "123456789", empty input, "a", an erased 0xFF unit, chunked vs one-shot, empty-chunk identity (6 tests).
- **test_image_validate.c** — image_validate (RA4M1 prior art) over a 256 KB fake flash: valid image, bad magic, header CRC, size bounds, SP and entry-point bounds, Thumb bit, payload CRC (15 tests).
- **test_can_update.c** — CAN Update Protocol v1 state machine against a fake 32 KB slot: happy path, HELLO ack, out-of-order and malformed NAKs, sequence-gap rewind, verify/erase/program/activate failures, session restart, custom command IDs, app-control opcodes NAKed in every phase (18 tests).
- **test_dfu_config.c** — Config block parser: v1 (76-byte) and v2 (80-byte) records, magic and version, name length limits, CRC failures, absent/erased block, per-device CAN ID defaults and fallback (20 tests).
- **test_slcan_codec.c** — SLCAN (Lawicel) codec: python-can open sequence, S0–S8 bitrates, standard/extended/RTR frames at DLC 0–8, malformed lines NAKed, encoder checks, round trips (19 tests).
- **test_app_control.c** — APP_INFO / ENTER_UPDATER codec: golden vectors shared with tools/can-flash, fail-closed request parsing, reply classification against the real can_update NAK, APP_INFO decode rejecting partial or foreign bursts (7 tests).
- **test_can_flash_host.c** — Host flashing engine against the real can_update engine on a RAM slot with a fake clock: multi-window transfers, dropped/duplicated data, lost ACKs, final-frame probes, CRC mismatch, oversize NAK, three-node scan, app-mode INFO and ENTER_UPDATER, retry limits, malformed replies, clock wrap (35 tests). With a file path as argv[1] it writes a bus trace and runs only test_clean_multi_window.
