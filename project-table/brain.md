# brain/
> Generated by /map. Do not edit manually — re-run /map to refresh.

ESP32-S3 (ESP32-S3-WROOM-1U-N16R8) ESP-IDF firmware that self-updates over W5500 Ethernet and HTTP, and acts as the CAN host that stages, recovers and flashes node boards.

### brain/
- **Responsibility:** ESP-IDF project root: build wiring, the 16 MB partition table, and committed sdkconfig defaults/overlays for the brain image.
- **Key files:** CMakeLists.txt, partitions.csv, sdkconfig.defaults, sdkconfig.skip_mark_valid
- **Relationships:** imports from: main/ (COMPONENTS main), ../components (EXTRA_COMPONENT_DIRS) — exposes: project `brain_ota`.

- **CMakeLists.txt** — Project file: sets EXTRA_COMPONENT_DIRS to ../components, builds only `main`, and sets CMAKE_OBJECT_PATH_MAX 259 on Windows hosts.
- **partitions.csv** — 16 MB table: nvs (0x9000), otadata (0xe000), phy_init, ota_0 and ota_1 (3 MB each, A/B), node_fw (2 MB staging, subtype 0x41), pkg (0x7E0000 at 0x820000, subtype 0x43).
- **sdkconfig.defaults** — Committed defaults (sdkconfig itself is generated and excluded): esp32s3, 16 MB flash, custom partition table, app rollback enabled, W5500 over SPI, console on UART0 with USB-Serial-JTAG secondary.
- **sdkconfig.skip_mark_valid** — Overlay setting CONFIG_BRAIN_OTA_SKIP_MARK_VALID=y for the rollback-test build.

### brain/main/
- **Responsibility:** All brain application code: entry and self-test, Ethernet bring-up, HTTP server and single job worker, A/B OTA writer, node CAN staging and recovery, and multi-node package relay.
- **Key files:** brain_ota.c, http_ota_server.c, package_update.c, node_flash.c, ota_update.c, eth_w5500.c
- **Relationships:** imports from: node_reset, can_link, can_flash_host (../components), update_pkg (../../src/boot), ESP-IDF OTA/HTTP/Ethernet/NVS/mbedtls APIs — exposes: eth_w5500_start, eth_w5500_wait_for_ip, eth_w5500_get_ip_info, http_ota_server_start, http_ota_server_resume_packages, node_flash_init, node_flash_transport, node_flash_enter_updater, node_flash_scan, node_flash_stage, node_flash_run, node_flash_recover, node_flash_recover_run, node_flash_app_info, node_flash_status, ota_update_begin, ota_update_write, ota_update_finish, ota_update_abort, ota_update_running_state_name, package_update_resume, package_update_blocked, package_update_stage, package_update_run, package_update_status.

- **brain_ota.c** — `app_main`: drives node reset GPIO3 LOW first, logs identity, inits the node CAN host, starts Ethernet and HTTP, runs the self-test (30 s IP wait; marks the image valid, or rolls back and reboots), then resumes any retained package.
- **eth_w5500.h** — Public API: eth_w5500_start, eth_w5500_wait_for_ip, eth_w5500_get_ip_info.
- **eth_w5500.c** — W5500 on SPI2 (MOSI 11, MISO 13, SCLK 12, CS 10, INT 9, RST 14, 20 MHz) under esp_eth and esp_netif DHCP; GOT_IP event bit.
- **http_ota_server.h** — Route contract on port 80, no authentication: GET /, POST /ota, GET /node/scan, POST /node/flash, POST /node/recover, GET /node/app_info, GET /node/status, POST /package, GET /package/status.
- **http_ota_server.c** — Registers the 9 URI handlers; one static `update_worker` task runs all mutating jobs (JOB_* enum) and returns 409 on overlap; OTA uploads stream to ota_update in 4 KB chunks.
- **ota_update.h** — Transport-independent A/B writer API (begin/write/finish/abort) and the power-loss behavior table.
- **ota_update.c** — Session state for one update at a time; checks the image magic on the first byte; logs progress per 10 %.
- **node_flash.h** — Node CAN host API (scan, stage, run, recover, app_info, status); NODE_FLASH_UPDATER_BOOT_MS = 1500.
- **node_flash.c** — TWAI on TX GPIO6 / RX GPIO7 at 250 kbit/s; stages node images into node_fw (length kept in RAM only); sends ENTER_UPDATER before HELLO; recovery pulses GPIO3 via node_reset; JSON-escaped status.
- **package_update.h** — Package API; resume is called once after the self-test, and a retained record can block mutating jobs.
- **package_update.c** — v1 package flow: stage into pkg, validate manifest and SHA-256, write the brain entry to the inactive OTA slot and reboot, then relay node entries in manifest order (ENTER_UPDATER → INFO → GPIO3 pulses); pending record kept in NVS (namespace "package", key "pending").
- **CMakeLists.txt** — idf_component_register: lists the main sources plus ../../src/boot/update_pkg.c, and the PRIV_REQUIRES components.
- **Kconfig.projbuild** — "Brain OTA" menu with BRAIN_OTA_SKIP_MARK_VALID (default n): leaves the image in PENDING_VERIFY so the next reset rolls back.
