### tests/
- **Responsibility:** Host-side C tests for bootloader pure logic, protocol codecs, and the CAN flash host, built with Unity and CMake/CTest (11 executables).
- **Key files:** `CMakeLists.txt`, all `test_*.c` files.
- **Relationships:** Builds core modules from `src/boot/` and components from `components/slcan_codec/` and `components/can_flash_host/`; links tests with vendored Unity under `unity/`. Target-only flash, bus I/O and hardware behaviour are left to firmware builds and bench validation.

- **CMakeLists.txt** — Configures C11 host test targets and CTest registration; builds Unity, the tested boot core and codec libraries, and the can-flash host library. Binds the update-package test to its fixture path.
- **test_app_control.c** — Tests APP_INFO / ENTER_UPDATER request encoding and parsing, response classification, golden vectors, string boundaries, and malformed or partial response rejection against the real updater engine.
- **test_board_profile.c** — Tests v1 and v2 board-profile encoding, parsing, validation (hold-HIGH and I2C rules), defaults, bitrate mappings, invalid records, v1 read through a v2-sized buffer, and the golden records shared with ESP-PROG-2-PY-CLI's tests (v1 in the file, v2 from `vectors/board_profile_v2.txt`).
- **test_boot_counter.c** — Exercises recovery-counter behavior using RAM-backed flash, including thresholds, sticky state, torn records, log wrap, and reset/clear cases.
- **test_can_flash_host.c** — Tests host-side CAN discovery, app probing, updater entry, and multi-window flashing with simulated nodes, RAM slot, fake clock, and transport/failure injection.
- **test_can_update.c** — Tests the CAN updater state machine using a RAM-backed NOR-like slot, including transfer, CRC verification, commit/activation, NAK paths, sequence rewind, and injected failures.
- **test_crc32.c** — Checks IEEE CRC32 golden values, edge cases, and equivalence of incremental and one-shot calculation.
- **test_dfu_config.c** — Tests parsing DFU configuration records and deriving CAN IDs, including record versions, validation outcomes, and fallback behavior.
- **test_i2c_bitbang.c** — Tests the bit-banged I2C master against a simulated open-drain bus and slave: exact bit sequence of a write, NACK, bus clear with idle/stuck/permanently stuck SDA, the clock-stretch budget, the SOLO ODU sequence, and the worst-case delay bound.
- **test_image_validate.c** — Tests image validation against a RAM image and metadata layout, covering validation results and size, stack-pointer, and entry-point boundaries.
- **test_slcan_codec.c** — Tests SLCAN command parsing and frame/reply encoding, including bitrate selection, frame types, DLC boundaries, malformed input, and round trips.
- **test_update_pkg.c** — Tests update-package v1 manifest parsing using generated/mutated byte buffers, including CRC, bounds, size, entry, reserved-field, product-name, and CAN-ID validation.
