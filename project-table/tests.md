## tests/
- **Responsibility:** Standalone CMake + CTest project (`bootloader_host_tests`, C11, extensions off, `-Wall -Wextra` / `/W4`) that builds `src/boot/{crc32,image_validate,can_update,dfu_config}.c` as a `boot_core` static library with no hardware includes, links each `test_*.c` against it plus vendored Unity, and registers each as a CTest test. Runs on x86; no target toolchain needed.
- **Key files:** `CMakeLists.txt`, `test_crc32.c`, `test_image_validate.c`, `test_can_update.c`, `test_dfu_config.c`
- **Relationships:** imports from `src/boot/` (crc32, image_validate incl. `boot_decide`, can_update, dfu_config); depends on `tests/unity/`. Usable standalone (`cmake -S tests -B build-host`) or via `add_subdirectory(tests)` from the root `CMakeLists.txt`.

- **CMakeLists.txt** — Builds the `unity` and `boot_core` static libraries and defines `add_host_test(name)`, which compiles, links and registers each test (4 registered: test_crc32, test_image_validate, test_can_update, test_dfu_config).
- **test_crc32.c** — Golden-vector tests for `crc32_ieee`: the "123456789" check value, empty input, single byte, an all-0xFF write unit, and a one-shot guard.
- **test_image_validate.c** — `image_validate()` against a fake 256 KB flash buffer, covering every result (valid, bad magic, header-CRC corruption, size zero/below-min/above-slot/at-boundary, SP below/at-base/above-end, entry in the bootloader or metadata region or Thumb bit clear, payload-CRC corruption), plus `boot_decide()` cases: valid record, valid record + marker, marker only, marker + torn record, no record with valid/erased SP, corrupt record, torn marker and one-wrong-word marker.
- **test_can_update.c** — `can_update_handle_frame()` against a fake NOR-flash HAL that enforces erase-before-program and write alignment: full happy path, wrong CAN ID, wrong version, out-of-order commands, size-OOB NAKs, seq-gap rewind, VERIFY CRC mismatch (metadata left erased), injected flash failures with recovery, HELLO restart mid-transfer, malformed DLC.
- **test_dfu_config.c** — `dfu_config_parse()` and `dfu_config_can_ids()` against an 80-byte fake config blob: v1/v2 name round-trips, erased or bad magic, bad version, length limits, bad CRC, mutated payload, empty strings; CAN-ID fallback for v1/no block, provisioned v2 IDs, boundary IDs, per-field fallback for out-of-range values, CRC coverage of the ID fields.
