### brain/
- **Responsibility:** Defines the ESP-IDF brain firmware project, its ESP32-S3 configuration, and its A/B plus staging partition layout.
- **Key files:** `CMakeLists.txt`, `partitions.csv`, `sdkconfig.defaults`, `sdkconfig.skip_mark_valid`.
- **Relationships:** Builds the `main/` component and shared components under `../components/`; its partition table supplies the OTA slots and persistent node/package staging areas used by `main/`. The SOLO IDU uses the same offsets in `node_updater/partitions_idu_16MB.csv`, which adds `cancfg`, `bootcnt` and a `factory` updater; packages are capped at 0x780000 so they fit both.

- **CMakeLists.txt** — Configures the ESP-IDF `brain_ota` project and adds shared components from `../components/`.
- **partitions.csv** — Defines NVS, OTA metadata, two application slots, disposable node-image staging, and retained package staging.
- **sdkconfig.defaults** — Sets ESP32-S3 target, 16 MB flash, custom partitions, boot rollback, and W5500 SPI Ethernet defaults.
- **sdkconfig.skip_mark_valid** — Alternate configuration for testing OTA rollback by leaving the new image pending verification.

### brain/main/
- **Responsibility:** Implements startup, networking, the HTTP update API, self-OTA, CAN node operations, and package staging/relay.
- **Key files:** `brain_ota.c`, `eth_w5500.c/.h`, `http_ota_server.c/.h`, `node_flash.c/.h`, `ota_update.c/.h`, `package_update.c/.h`, `CMakeLists.txt`, `Kconfig.projbuild`.
- **Relationships:** `brain_ota.c` initializes the shared CAN host and Ethernet before starting the HTTP server; the server serializes mutating jobs and delegates them to `ota_update`, `node_flash`, and `package_update`. These modules use shared components for CAN transport, node reset, and package manifest parsing.

- **CMakeLists.txt** — Registers brain application sources and declares ESP-IDF and shared component dependencies.
- **Kconfig.projbuild** — Declares the option to skip marking a freshly booted OTA image valid for rollback testing.
- **brain_ota.c** — Entry point that initializes services, logs firmware/OTA state, and validates a newly updated image after Ethernet obtains an IP address.
- **eth_w5500.c** — Initializes the W5500 over SPI2 and provides Ethernet/DHCP state and address information.
- **eth_w5500.h** — Declares the W5500 startup, IP-wait, and IP-info interface.
- **http_ota_server.c** — Implements the HTTP status, self-OTA, node management, and package routes, with a worker to serialize mutating operations.
- **http_ota_server.h** — Declares HTTP server startup and package-resume entry points; documents the route contract.
- **node_flash.c** — Stages node firmware, discovers running apps and parked updaters, flashes them over CAN, and performs node recovery.
- **node_flash.h** — Declares the node flashing, scanning, app-info, recovery, and status interfaces.
- **ota_update.c** — Writes and validates an application image in the inactive OTA slot, switches the boot partition, and supports aborting an update.
- **ota_update.h** — Declares the transport-independent A/B self-update interface and its session/error contract.
- **package_update.c** — Stages and validates update packages (capped at 0x780000), records pending relay state, updates the brain if needed, and relays node images.
- **package_update.h** — Declares package resume, readiness/blocking, staging, execution, and status interfaces.
